# Як додати сценарій без програміста

Формат — стартовий формат організаторів Завдання 1. Будь-який сценарій у цьому форматі програється. Поле `podacha` необовʼязкове: воно додає репліку персонажа, заголовки й поведінку в режимі тиску часу.

## Найпростіше: перевірити файл у застосунку

1. Скопіюйте наявний файл, наприклад `data/stsenarii/S07-tse-zh-vid-shchyroho-sertsia.json`, і змініть тексти в будь-якому текстовому редакторі.
2. Відкрийте застосунок → на обкладинці **«+ Свій сценарій»** → оберіть файл.
3. Якщо є помилки, застосунок перелічить їх простими реченнями (наприклад, «варіант B1 веде до неіснуючого вузла V9»). Якщо помилок немає, сценарій зʼявиться у вкладках до кінця сеансу.

## Щоб сценарій був в усіх

1. Покладіть файл у `data/stsenarii/` і допишіть назву в `data/stsenarii/index.json`.
2. Виконайте `node tools/build.mjs`. Це перевірка, офлайн-збірка, оновлена карта рішень у `docs/stsenarii.md` і строга копія в `dist/strict/` для `zibraty.py` організаторів.
3. Через вебсервер (GitHub Pages чи локальний) застосунок читає JSON напряму, без збірки.

## Чек-лист автора

- [ ] Цінності справді конфліктують (`tsinnosti_v_konflikti`): у кожного варіанта є і виграш, і ціна. Валідатор попередить, якщо варіант кращий за всіма трьома вимірами.
- [ ] Щонайменше 3 послідовні етапи (вимога до сценаріїв команди).
- [ ] `zvorotnyi_zviazok` описує рішення, а не людину. Без ярликів «нечесний», «корупціонер».
- [ ] Кожна норма — з `data/normy.json`, з поясненням `yak_zastosovuietsia`. Нову норму спершу додають у перелік із цитатою, редакцією і джерелом звірки. Вигадана норма гірша, ніж відсутня.
- [ ] `zastosovnist` — на кого норми поширюються і що лишається спірним. Курсанти ВВНЗ не є субʼєктами пп. «г» п. 1 ч. 1 ст. 3 Закону.
- [ ] `dzherelo_vypadku` — вигаданий або знеособлений, без можливості впізнати людей, підрозділи чи події.
- [ ] `shi` — чесно: чи використовувався ШІ, для чого і як перевірено людиною.
- [ ] `perevirka_zmistu.fakhivets_dzpk` = «не проведено», доки сценарій не переглянув фахівець.
- [ ] Жодної службової інформації чи інформації з обмеженим доступом.

## Шпаргалка розширення `podacha`

| Де | Поле | Приклад |
|---|---|---|
| сценарій | `zagolovok` | `["Під мою", "відповідальність."]` |
| сценарій | `knopka`, `ikonka` | `"Відповісти"`, `"phone"` / `"box"` / `"play"` |
| вузол | `zagolovok`, `khto`, `replika` | `"Тиск у відповідь"`, `"Заступник начальника"`, `"Ти мені не довіряєш?…"` |
| вузол | `inertsiia` | `"A2"` — варіант, що спрацює, коли вийшов час |
| вузол | `rozdum` | Питання для рефлексії, якщо маршрут завершився тут |
