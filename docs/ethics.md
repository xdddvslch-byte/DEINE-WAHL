# Можливі зловживання і запобіжники

Головний ризик тренажера з доброчесності — перетворити навчальний інструмент на інструмент оцінки людей. Ми закладаємо захист на рівні архітектури, а не лише правил користування.

| Можливе зловживання | Чому це шкідливо | Запобіжник у рішенні |
|---|---|---|
| Використати бали для атестації, відбору чи «рейтингу доброчесності» | Люди почнуть вгадувати очікувану відповідь замість міркувати. Навчальна ситуація не відображає реальну поведінку | Немає загального балу, лише три осі в балансі. Результат не зберігається й не експортується. Розбір прямо каже, що бали не придатні для оцінювання |
| Командир чи викладач переглядає індивідуальні відповіді | Тиск і самоцензура, зникає чесна рефлексія | Немає акаунтів і сервера. У SCORM/LMS передається лише «completed», без балів і виборів |
| Деанонімізація в груповому режимі | Страх висловити непопулярну позицію | Лише лічильники без імен і пристроїв, без мережі. Розподіл приховано до команди ведучого. Після закриття сторінки нічого не лишається |
| Сценарій як «довідка з права» | Помилки в переказі норми ведуть до неправильних дій у реальності | Дослівні цитати з редакцією і статусом звірки з переліку організаторів; блок «на кого поширюються норми»; статус перегляду фахівцем |
| Неперевірені або впізнавані кейси | Шкода репутації реальних людей і підрозділів | `dzherelo_vypadku` і `perevirka_zmistu` обов'язкові й видні користувачу; імпортований сценарій живе лише один сеанс |
| Згенерований ШІ зміст подається як експертний | Хибна впевненість у правильності | поле `shi` обов'язкове і показується в розборі; ШІ не працює всередині продукту, висновки ухвалюють явні правила |
| Ярлики для людини («нечесний») | Стигматизація замість навчання | Зворотний зв'язок описує рішення й наслідки. Це вимога в чек-листі автора |

## Що система свідомо не робить

- Не збирає персональних даних і не має акаунтів.
- Не ставить загальної оцінки й не ранжує людей.
- Не передає індивідуальні результати викладачу, командиру чи LMS.
- Не використовує ШІ для висновків: однакові вибори завжди дають однаковий розбір.
- Не вимагає інтернету.
